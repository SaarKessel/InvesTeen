# InvesTeen - Product Requirements (concise)

Source: Saar Kessel's "InvesTeen - Master Product & Development Prompt" (WhatsApp, 2026-10-18).

## What it is
Educational platform (FinTech x EdTech) teaching Israeli teens (12-17) money and investing
through a virtual investment simulator, structured curriculum, missions, and an AI mentor.
Educational only: no real money, no real trades, no investment advice, no return promises.

## Primary audience
Teens 12-17 (age bands 12-13 / 14-15 / 16-17). Secondary: parents/guardians. Future: schools.

## MVP scope (brief section 15)
Landing page, auth + age-appropriate onboarding, dashboard, virtual account (10,000 virtual units),
asset catalog (fictional educational dataset, clearly labeled), asset details + charts,
virtual buy/sell with validation and atomic execution, transaction history, portfolio valuation
and allocation, >=5 lessons, >=3 interactive missions, AI mentor with safety boundaries
(local educational rule-based fallback until Saar supplies an AI provider key), progress +
achievements, initial parent-access flow, Hebrew RTL responsive design, seed data + reproducible
local env, automated tests for financial calculations and permissions.

## Core principle
Reward good financial reasoning, not virtual profits. Distinguish outcomes from decision quality.

## Out of scope for MVP
Real-money anything, brokerage integrations, limit orders, classrooms, monetization,
payment cards, targeted ads.
